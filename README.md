## 绩效考核与激励发放

### 1. 绩效考核周期
- 按月考核：每月 1 日至当月最后一天为一个完整周期。
- 每月第 3 个工作日前完成上月绩效评分与结果确认（工作日不含周末及法定节假日）。

### 2. 绩效评分规则
- 绩效总分 = 目标达成（50%）+ 能力表现（30%）+ 协作与合规（20%）。
- 各维度满分 100 分，按权重折算后汇总为最终得分。
- 目标达成衡量业务目标完成情况，能力表现衡量岗位专业能力，协作与合规衡量团队协作与制度遵循。

### 3. 绩效等级划分
- 绩效分数按整数计分，不使用小数。
- A: 90 分及以上
- B: 80-89 分
- C: 70-79 分
- D: 1-69 分
- 0 分视为未完成有效评估，需先完成补评后再按规则定级。

### 4. 激励发放标准
- A: 发放绩效激励基数的 120%
- B: 发放绩效激励基数的 100%
- C: 发放绩效激励基数的 60%
- D: 不发放绩效激励

### 5. 发放时间与要求
- 激励金额随次月薪资统一发放。
- 对评分结果有异议者需在结果公布后 2 个工作日内提交复核申请。
- 复核申请通过公司办公自动化（OA）系统提交，需附评分记录与相关佐证材料，并抄送直属主管与人力资源。
- 复核由直属主管与人力资源共同处理，并在 3 个工作日内反馈结果。
- 如直属主管涉及利益冲突，由部门负责人或指定独立评审人接替复核。
