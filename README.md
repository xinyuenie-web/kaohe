## 绩效考核与激励发放

### 1. 绩效考核周期
- 按月考核，每月 1 日至当月最后一天为一个完整周期。
- 每月第 3 个工作日前完成上月绩效评分与结果确认。

### 2. 绩效评分规则
- 绩效总分 = 目标达成（50%）+ 能力表现（30%）+ 协作与合规（20%）。
- 各维度满分 100 分，按权重折算后汇总为最终得分。

### 3. 绩效等级划分
- A：90 分及以上
- B：80–89 分
- C：70–79 分
- D：69 分及以下

### 4. 激励发放标准
- A：发放绩效激励基数的 120%
- B：发放绩效激励基数的 100%
- C：发放绩效激励基数的 60%
- D：不发放绩效激励

### 5. 发放时间与要求
- 激励金额随次月薪资统一发放。
- 对评分结果有异议者，应在结果公布后 2 个工作日内提交复核申请。
